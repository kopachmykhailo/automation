
# Лабораторна робота №1

## Розгортання середовища автоматизації тестування

**Дисципліна:** Автоматизація тестування  
**Спеціальність:** F2 «Інженерія програмного забезпечення»  
**Варіант:** 8  
**Виконавець:** [Копач Михайло]  
**Група:** [2]

### Мета роботи

Розгорнути середовище автоматизації тестування на базі Node.js
і TypeScript, налаштувати Vitest, ESLint і Prettier, реалізувати
модуль обчислення відстані між двома точками та перевірити його
автоматизованими тестами.

### Опис проєкту

Проєкт обчислює відстань між двома точками на площині та перевіряє
коректність координат.

### Структура проєкту

- `src/distance.ts` — реалізація функції.
- `tests/distance.test.ts` — автоматизовані тести.
- `vitest.config.ts` — конфігурація тестування.
- `tsconfig.json` — налаштування TypeScript.
- `eslint.config.mjs` — правила статичного аналізу.
- `.prettierrc` — налаштування форматування.
- `.gitignore` — файли, які не потрібно додавати до Git.
- `package.json` — залежності та команди проєкту.

### Запуск тестів

```bash
npm test
```

### Перевірка покриття

```bash
npm run coverage
```

HTML-звіт створюється у `coverage/index.html`.

### Перевірка коду

```bash
npm run lint
```

### Форматування

```bash
npm run format
```
