
# Лабораторна робота №1

## Розгортання середовища автоматизації тестування

**Дисципліна:** Автоматизація тестування  
**Спеціальність:** F2 «Інженерія програмного забезпечення»  

**Варіант:** 8

**Виконавець:** [Копач Михайло]  
**Група:** [2]

### Мета роботи

Розгорнути середовище автоматизації тестування на базі Node.js
і TypeScript, налаштувати Vitest, ESLint і Prettier, реалізувати
модуль обчислення відстані між двома точками та перевірити його
автоматизованими тестами.

### Опис проєкту

Проєкт обчислює відстань між двома точками на площині та перевіряє
коректність координат.

### Структура проєкту

- `src/distance.ts` — реалізація функції.
- `tests/distance.test.ts` — автоматизовані тести.
- `vitest.config.ts` — конфігурація тестування.
- `tsconfig.json` — налаштування TypeScript.
- `eslint.config.mjs` — правила статичного аналізу.
- `.prettierrc` — налаштування форматування.
- `.gitignore` — файли, які не потрібно додавати до Git.
- `package.json` — залежності та команди проєкту.

### Запуск тестів

```bash
npm test
```

### Перевірка покриття

```bash
npm run coverage
```

HTML-звіт створюється у `coverage/index.html`.

### Перевірка коду

```bash
npm run lint
```

### Форматування

```bash
npm run format
```

# Лабораторна робота №2

## Модульне тестування бізнес-логіки засобами Vitest

**Варіант:** 8

**Завдання:** `mergeItems(items)` об’єднує позиції з однаковим `sku`, підсумовуючи кількість.

### Реалізація варіанта

- Результат зберігає порядок першої появи кожного SKU та не змінює вхідний список.
- Для однакового SKU ціна має збігатися; інакше функція викидає `SKU_PRICE_MISMATCH`.
- Порожній або некоректний SKU, від’ємна чи нечислова ціна, а також непозитивна або дробова кількість спричиняють `INVALID_ITEM`.
- Порожній список повертає порожній список.

### Запуск і результати

```bash
npm test
npm run coverage
npm run lint
```

У наборі ЛР2 є параметризовані перевірки кількості та межі мінімальної допустимої кількості: `0`, `1`, `2`. Очікувані результати задані явно. Тести перевіряють також винятки, межі знижки й безкоштовної доставки та обчислення підсумкової суми.

- Успішно пройдено 45 тестів у двох файлах.
- Покриття рядків, гілок і функцій: 100%.
- ESLint: помилок не виявлено.
- Звіт покриття: `coverage/index.html`.

### Експеримент із тестом без твердження

Тимчасовий тест викликав `calcOrderTotal`, але не перевіряв результат. Під час експерименту пройшло 46 тестів, а покриття рядків, гілок і функцій залишилося 100%. Тест видалено після вимірювання. Експеримент показує, що покриття фіксує виконання коду, але не доводить правильність результату чи наявність змістовних перевірок.
